# -
Данный проект представляет собой информационную систему для учёта посещаемости студентов. Система позволяет преподавателю создавать занятия, просматривать список студентов и отмечать их присутствие или отсутствие. Также можно просматривать информацию о посещаемости и статистику. Система упрощает работу преподавателя и экономит время.
